# Instituto Simone Guimarães

Site institucional do Instituto Simone Guimarães - Neuropsicologia e Psicologia Clínica em Salvador e Cruz das Almas, Bahia.

## Sobre

Site desenvolvido para apresentar os serviços, diferenciais e canais de contato do Instituto, com foco em experiência do paciente e conversão via WhatsApp.

## Funcionalidades

- **Design responsivo** otimizado para desktop, tablet e mobile
- **Formulário de agendamento** com envio direto via WhatsApp
- **Carrossel de depoimentos** com navegação por swipe e teclado
- **Scroll reveal** com Intersection Observer
- **Menu mobile** com animação hamburger → X
- **Acessibilidade** (focus-visible, prefers-reduced-motion, skip-to-content)
- **SEO otimizado** (Schema.org/JSON-LD, Open Graph, meta tags)
